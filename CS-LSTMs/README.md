# CS-LSTMs ICLR 2026
Contextual and Seasonal LSTM for Time Series Anomaly Detection
- Introducing a noise decomposition strategy to better capture normal patterns by eliminating the non-stationarity of time series effectively, thereby improving predictive accuracy and anomaly detection robustness.
- Using a dual-branch architecture: one branch leverages frequency domain analysis to model long-term periodicity and its evolution, while the other captures short-term local dynamics. The combination of the two effectively enhances the ability of anomaly detection.

## Get Started
python train.py --data_name Yahoo --data_dir ./data/Yahoo  --window 240 --seasonal_window 48 --cycle 48 --contextual_window 4 --step 2  --save_file ./result.txt  --learning_rate 0.0005

| Parameter | Defination |
|--------|--------|
| data_dir   |  dataset address | 
| window   | size of window   | 
| d_model | dimension of LSTM hidden layer | 
| seasonal_window | dimension of seasonal window |
| cycle | length of the periodicity |
| contextual_window | dimension of contextual window |
| step | step of the contextual window |
| gpu   | gpu number | 
| kernel_size   | size of small window in LFM   | 
| dropout_rate   | dropout rate   | 
| use_label   | 1:supervised 0:unsupervised   | 
| max_epoch  | training epoches   | 
| batch_size  | batch_size   | 
| learning_rate  | learning rate   | 
| data_pre_mode  | datapreprocessing mode  | 
| save_file   | address of save file   |
